# Джарвис

Голосовой помощник для Windows: слушает, думает и управляет компьютером — открывает программы,
ищет в интернете, читает экран, ставит таймеры, управляет музыкой и громкостью.

## Как получить

Джарвис — для подписчиков [Boosty Тимохи](https://boosty.to/timsheko) **со 2-го уровня**.

1. Скачай последний `Jarvis-x.y.z-x64.msi` в [Releases](https://github.com/Timoha589/Jarvis/releases/latest) и запусти.
   Права администратора не нужны. Windows может предупредить о неизвестном издателе:
   «Подробнее» → «Выполнить в любом случае».
2. Ключ активации — в Discord: команда `/timoha_premium`, кнопка «🤖 Джарвис».
3. Вставь ключ в окно активации. Ключ работает на одном компьютере; сменить компьютер можно
   кнопкой «Отвязать компьютер» там же.

ИИ (DeepSeek) и распознавание речи уже входят в подписку. В настройках можно подключить и свои
ключи ИИ или распознавать речь локально на своём компьютере.

Джарвис сам проверяет здесь обновления и предлагает поставить новую версию.

## Требования

Windows 10/11 x64, микрофон, ~2 ГБ на диске. Видеокарта NVIDIA не обязательна.

## Расширение для браузера

В папке [browser-extension](browser-extension) — расширение «Джарвис» для Chrome, Edge, Brave и Helium:
с ним Джарвис работает в твоём обычном браузере со всеми логинами. Как поставить — в его
[README](browser-extension/README.md).
