# Расширение «Джарвис» для Chromium-браузеров

Даёт Джарвису работать в твоём обычном браузере (Helium, Chrome, Edge, Brave),
со всеми твоими логинами, как это делает расширение Claude для Chrome. Все
инструменты `browser_*`, которые Джарвис уже знает, работают как раньше.

## Установка

1. Открой `chrome://extensions` и включи «Режим разработчика».
2. Нажми «Загрузить распакованное» и выбери эту папку (`browser-extension`).
3. В `config.yaml` в подключении `browser` замени
   `"--user-data-dir"` и путь под ним на одну строку `"--extension"`.
   `--executable-path` оставь: по нему Джарвис открывает страницу подключения.

## Как это работает

Джарвис ходит в браузер через Playwright MCP в режиме `--extension`. При первом
`browser_*` он открывает `connect.html` этого расширения с адресом своего
WebSocket на localhost; расширение подключается, закрывает эту вкладку и дальше
пересылает команды `chrome.debugger` (протокол Playwright extension v2).

Джарвису видны только:
- вкладка, на которой ты был в момент подключения;
- вкладки, которые он открыл сам, и те, что открылись из них;
- любая вкладка, на которой ты нажмёшь кнопку расширения.

Пока он подключён, на значке горит `ON`, а над вкладками Chrome показывает
плашку «отлаживает этот браузер». «Отмена» на плашке забирает вкладку у Джарвиса.

## Ограничения

- ID расширения должен совпадать с тем, что ждёт Playwright, поэтому в
  `manifest.json` стоит ключ Playwright Extension. Ставить их оба нельзя.
- Окно, перекрытое другими, Chromium считает скрытым и перестаёт рисовать, и клик
  Джарвиса виснет на «waiting for element to be stable». Лечится ключом запуска
  браузера `--disable-features=CalculateNativeWinOcclusion` или тем, что окно
  браузера видно на экране.
- После обновления `@playwright/mcp` протокол может смениться: тогда страница
  подключения так и напишет.
